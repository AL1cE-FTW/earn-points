# earn-points — バスツアー会員ポイント制度

バスツアーの旅行客に付与する会員向けポイント制度と、その管理システムです。

- **外部サービス非依存**: LINE・クラウド・決済サービス・CDN などを一切使いません。Python 3.9 以上の標準ライブラリだけで動き、データは1つの SQLite ファイル（既定 `points.sqlite3`）に保存されます。`pip install` も不要です。
- **会員証**: 会員番号（`BT` + 8桁、末尾は入力ミス検出用のチェックディジット）を印刷した会員証を窓口で渡します。
- **会員ページ**: お客様は会員番号＋暗証番号でログインし、残高・ランク・有効期限・履歴を確認できます（スマートフォン対応）。

## 制度の概要

| 項目 | 内容 |
|---|---|
| 入会特典 | 300pt |
| ツアー参加 | 支払額（ポイント利用分を除く税込代金）100円ごとに1pt × ランク倍率 × キャンペーン倍率 ＋ キャンペーン加算 |
| 誕生月特典 | 出発日が誕生月なら +200pt |
| ご紹介特典 | 紹介した方の初参加時に紹介者へ 500pt |
| 会員ランク | 直近1年の参加回数で判定：レギュラー(×1) / シルバー 3回〜(×1.5) / ゴールド 6回〜(×2) |
| 利用 | 100pt単位、1pt＝1円でツアー代金に充当（代金が上限） |
| 有効期限 | 付与日から2年後の月末。期限の近いポイントから消費 |
| 取消・中止 | 利用ポイントは元の有効期限のまま返還 |
| 退会 | 保有ポイントは失効 |

数値はすべて [`points/rules.py`](points/rules.py) にまとめてあり、ここを変えるだけで制度を調整できます。会員向けの規約ひな形と法令面の確認メモは [`docs/ポイント規約.md`](docs/ポイント規約.md) にあります。

> 上記の数値は一般的なポイント制度を参考にした**初期案**です（特定の調査や他社事例を出典とするものではありません）。利益率に合わせて調整してください。

## 使い方

```sh
python3 -m points demo     # （任意）サンプル会員・ツアーを投入
python3 -m points serve    # 画面を起動 → http://127.0.0.1:8000/
```

- 会員ページ: `http://127.0.0.1:8000/`
- スタッフ画面: `http://127.0.0.1:8000/admin`
  初回起動時に管理パスワードが表示されます。環境変数 `POINTS_ADMIN_PASSWORD` で指定するか、`python3 -m points passwd` で変更できます。
- 社内LANの他の端末から使う場合は `--host 0.0.0.0` を付けます。インターネットへ公開する場合は HTTPS 化（リバースプロキシ等）を必ず行ってください。

主なオプション: `--db ファイル名`（環境変数 `POINTS_DB` でも可）、`--port 番号`

### 日々の運用

1. **入会**: 「新規入会」で登録 → 会員証を印刷してお渡し（暗証番号はお客様に決めてもらう）
2. **ツアー登録**: 「ツアー」でツアーコード・出発日・代金・キャンペーン倍率を登録
3. **予約**: ツアー画面で会員番号を入力し「残高確認」→ 利用ポイントを入力して「予約登録」
4. **催行完了**: 出発日以降にツアー画面で不参加者にチェックを付けて「催行完了として付与」
5. **取消・中止**: 予約ごとの「取消」または「ツアーを中止」で利用ポイントを自動返還
6. **失効処理**: 残高表示は期限切れを自動で除外しますが、台帳に失効記録を残すため毎日 `python3 -m points expire` を cron 等で実行してください（管理トップのボタンでも可）

### バックアップ

データは SQLite ファイル1つです。サーバ停止中にコピーするか、稼働中なら `sqlite3 points.sqlite3 ".backup backup.sqlite3"` で取得できます。

## 設計メモ

- ポイントの増減はすべて取引台帳 `point_txns` に記録し、有効期限管理のため付与単位の残高 `point_lots` を持ちます。どの付与分を何pt使ったかを `lot_usages` に残すので、取消時に元の有効期限で返還できます。
- 担当者名を操作ごとに記録します（スタッフログイン時に入力）。
- 会員の暗証番号と管理パスワードは PBKDF2-SHA256 でハッシュ化して保存します。会員ログインは5回失敗で15分ロックします。
