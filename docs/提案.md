# 提案：LINE 連携と招待制「道ツアー」

> 状態：**検討中（たたき台）**。最終更新 2026年10月5日
> 仕様はまだ決まっていません。「[これから詰めたいこと](#これから詰めたいこと)」を決めたうえで、設計と実装に進みます。

## 背景と目的

- ツアーには、**通常ツアー**（価格が安い）と **道ツアー**（価格が高い）の2種類がある。
- 通常ツアーに何度も参加している**常連の会員に、道ツアーを案内したい**。案内は招待制にするイメージ。
- 案内の手段として、**LINE 公式アカウント**からの配信と、ポイント制度を連携させたい。

## 結論

LINE 連携は可能です。ただし、次の進め方をおすすめします。

1. **招待の仕組みを、先に自社システムだけで作る。** ツアーの種類、招待の条件、招待された人だけが予約できる仕組み、会員アプリへの招待の表示です。今のシステムには会員ごとの参加回数とランクがあるので、LINE なしで作れます。
2. **そのあとで、LINE を「招待の連絡手段」として付ける。**

この順番には2つの利点があります。LINE を使わない常連にも同じ招待が届きます。また、LINE をやめたくなっても仕組みはそのまま残ります。

> **方針の変更について**：このシステムは最初に「LINE などの外部サービスは使わない」という方針で作りました。LINE 連携はこの方針を変えることになるため、進める場合は改めてご判断ください。

## 招待制「道ツアー」の流れ（イメージ）

```
① 会員が LINE 公式アカウントを友だち追加し、会員番号と暗証番号で一度だけ ID 連携する
② スタッフが道ツアーを登録し、招待条件を決める（例：直近1年で通常ツアーに3回以上参加）
③ システムが条件に合う会員を自動で抽出する
   ├ LINE 連携済みの方 → LINE で招待メッセージを送る
   └ 未連携の方      → 一覧を出して、窓口・電話・郵送でご案内
④ 道ツアーは、招待された会員だけが予約できる
⑤ 参加すると道ツアー限定の特典ポイント（例：+1,000pt）
```

## システムに追加するもの（案）

| 段階 | 追加するもの | LINE |
|---|---|---|
| 1 | ツアーに「種類」（通常／道）を持たせる | 不要 |
| 1 | 道ツアーごとに「招待条件」（例：直近1年の通常ツアー参加回数）を設定できるようにする | 不要 |
| 1 | 条件に合う会員の一覧をスタッフ画面に出す。電話・郵送用に印刷もできる | 不要 |
| 1 | 招待された会員だけが道ツアーを予約できるようにする | 不要 |
| 1 | 会員アプリに「あなたへの招待」を表示する | 不要 |
| 1 | 道ツアーの特典ポイント（加算や倍率） | 不要 |
| 2 | 会員と LINE アカウントの ID 連携 | 必要 |
| 2 | 条件に合う連携済みの会員へ、LINE で招待を送る | 必要 |
| 2 | （必要なら）LINE 広告の配信先に常連のリストを使う | 必要 |

段階1は、今の画面デモ（github.io）でも見た目と流れを確認できます。段階2はサーバが必要です（「[注意が必要な点](#注意が必要な点)」）。

## LINE でできること

| やりたいこと | 方法 |
|---|---|
| LINE の友だちと会員番号を結びつける | **ID 連携**。LINE ログイン・Messaging API・LIFF のいずれかを使う |
| 常連の人にだけ送る | **オーディエンス**。LINE のユーザー ID の一覧をアップロードして、送る相手を絞り込む |
| 一人ずつ個別に送る | **Messaging API** で、条件に合った会員に直接メッセージを送る |
| LINE の中の広告に出す | **LINE 広告**。オーディエンスは広告の配信先の絞り込みにも使える |

「広告の配信」が、LINE 公式アカウントから友だちへのメッセージなのか、LINE アプリ内の有料広告（LINE 広告）なのかで、やることと費用が変わります。

## 費用（LINE 公式アカウント）

| プラン | 月額（税別） | 送れる通数 |
|---|---|---|
| コミュニケーション | 無料 | 200通 |
| ライト | 5,000円 | 5,000通 |
| スタンダード | 15,000円 | 30,000通（超えた分は追加料金） |

- **通数の数え方**：1回の配信を1人が受け取るごとに1通と数えます。例えば会員1,000人に月4回送ると4,000通で、ライトプランに収まります。招待制なら送る相手は常連だけなので、通数はさらに少なくなります。
- **2026年10月の改定**：追加メッセージの単価が変わりました（月20万通まで1通3円、それを超える分は1通2.5円、税別）。影響を受けるのはスタンダードプランで追加分を買う場合だけで、月額と無料通数の変更は告知されていません。
- **未確認の点**：
  - Messaging API で個別に送った分も同じ通数に数えられると考えていますが、確認できていません。
  - 公式の料金ページは作業環境のネットワーク制限で開けず、上の表は解説記事による情報です。契約前に公式ページで確かめてください。
  - LINE 広告を使う場合は、上の費用とは別に広告費がかかります。

## 注意が必要な点

- **サーバが必要になる**：LINE との連携には、インターネットからアクセスできるサーバが必要です。GitHub Pages の画面デモでは実現できません（静的なファイルしか公開できないため）。秘密の鍵（チャネルアクセストークン）を安全に置く場所も要ります。サーバ版（`points/`）を拡張し、HTTPS で公開する形を想定しています。
- **データの扱いが変わる**：会員と LINE アカウントの結びつきを持つことになります。プライバシーポリシーと会員規約（[`ポイント規約.md`](ポイント規約.md) 第8条）の改定と、お客様の同意が必要です。法的な扱いは専門家に確認してください。
- **LINE を使わない常連もいる**：バスツアーの常連はご年配の方も多いと思われ、LINE を使わない方もいるはずです。そうした方には、窓口・電話・郵送でご案内する手段も残します。

## これから詰めたいこと

| # | 決めること | 選択肢・例 |
|---|---|---|
| 1 | 常連の定義 | 通常ツアーに何回以上参加したら招待するか。期間はいつからいつまでか（例：直近1年で3回）。今のランク（シルバー以上など）を使うか |
| 2 | 道ツアーの扱い | 招待された人しか予約できない／招待された人が先に予約でき、空きがあれば一般にも出す |
| 3 | ポイントの扱い | 道ツアーで特典ポイントを付けるか。ポイントで代金を払えるようにするか（高額なので上限を決めるか） |
| 4 | 「広告」の意味 | LINE 公式アカウントからのメッセージ／LINE 広告（有料）／その両方 |
| 5 | 会員と LINE の状況 | 今の会員と LINE の友だちのおおよその人数。LINE を使っていない常連の割合 |
| 6 | 運用体制 | 誰が配信するか。サーバをどこで動かすか（事務所の PC、レンタルサーバなど） |
